# 生产部署前检查清单

## 必须完成

- 准备独立的生产 PostgreSQL，设置 `DATABASE_URL`、`DATABASE_USERNAME`、`DATABASE_PASSWORD`。
- 设置 `SPRING_PROFILES_ACTIVE=prod`，生产配置会关闭 Swagger 和接口文档。
- 设置持久化的 `FILE_STORAGE_DIR`，并纳入备份；不得使用临时目录。
- 首次启动使用不少于 12 位的随机管理员密码；创建成功后从运行环境移除初始化密码。
- 配置 HTTPS 反向代理，外部只开放 HTTPS；数据库和对象存储不得直接暴露公网。
- 导入真实厂区、组织、岗位、人员及权限，并由安全经理复核数据范围。
- 配置数据库每日备份、附件目录备份和恢复演练，明确保留周期与责任人。
- 完成等保、安全测试、弱口令检查、漏洞扫描和日志留存策略。

## 上线验证

- 管理端登录、退出、令牌自动刷新正常。
- 不同污水厂之间组织、人员和业务数据不能交叉访问。
- 风险、检查、隐患和危险作业至少各走通一条完整业务闭环。
- 培训材料、隐患图片等附件上传、读取和备份正常。
- 证书、设备、消防器材、应急物资、职业检测和体检到期提醒日期正确。
- 访客二维码使用现场手机网络能够访问，风险图和疏散图显示清晰。
- 关键操作留痕时间、操作者及所属厂区正确。

## 建议完成

- 接入短信、企业微信或其他企业消息渠道发送任务和到期提醒。
- 配置数据库监控、服务健康监控、磁盘容量预警和异常告警。
- 组织厂长、安全经理、安全员、班组长和一线员工完成试运行验收。
- 正式切换前冻结基础数据，保留回退方案和联系人清单。
