# WaterX 工艺管理 MVP：业务规则与数据关系 V0.1

更新：2026-09-06。用户已确认首版聚焦人工日数据收集、汇总计算与目标偏差分析，并在本地试用后人工校核。专业参数为项目待校核值，不代表通用排放标准。

## 1. 业务目标与范围

工艺人员每天从设计参考、当日有效工况目标和当日运行事实生成一份可解释、可追溯的诊断。设计标准、工况、运行数据、诊断、日报使用同一指标目录。日报读取诊断快照，不另设可编辑的结果来源。

本批次交付主产品内的本地可运行闭环。菜单“工艺诊断分析”暂保留名称，首版不做原因诊断、操作指导、优化动作和设备指令。外部自动采集、正式数据库、跨用户协作及岗位级审批不在本批范围；不保留没有实际作用的自动采集按钮。

## 2. 对象与唯一性

| 对象 | 唯一性 | 更新规则 |
| --- | --- | --- |
| 设计标准 | 项目一份，内部按工艺线分组 | 保存新版本，填写文件来源、生效日期和修改原因 |
| 工况 | 项目、工艺线内多套 | 草稿可重叠；启用工况生效区间不可重叠；保存保留修订 |
| 日运行数据 | 项目ID＋工艺线＋业务日期 | 一条当前记录，多次保存形成版本；锁定后更正须说明原因 |
| 日诊断 | 同上 | 更新生成草稿；保存同日结果需确认；锁定后新修订须说明原因 |
| 日报 | 引用日诊断版本 | 历史列表、查看、打印、导出；不独立改写指标 |

业务日期统一按北京时间自然日。每日数据可多次人工修改和补录，但不生成多个同日列表行。本版不建设瞬时数据、班次或多来源聚合模型。

## 3. 指标和专业口径

复用主产品现有完整指标分类、编码、名称和单位。目前为兼容旧数据，关联键沿用“分类::名称”；重命名不会自动迁移，后续应引入不可变指标 ID 并提供显式迁移，不能直接改名造成旧数据失联。设计固定属性、现场原始值、受控公式结果分别标识。公式按明确的指标身份取依赖，禁止按数组位置取数。

设计值是参考；状态由工况目标和实际值比较产生。设计文件、排污许可/适用排放要求、项目运行目标不是同一概念。当前告警是运行偏差提示，不能直接认定违法超标或确定工艺故障。

控制类型包括定值、区间、上限、下限、文本匹配和仅参考。数值解析必须完整匹配；缺失不等于0；目标为0时显示绝对偏差，不除零。区间内显示范围内，超界按最近边界计算差值。无目标、无有效工况或未配置规则单列，不算正常。

偏差预警/告警容差为项目参数，保留“待校核”状态。不从行业资料任意抽取阈值作为所有项目的正式规则。膜片堵塞率、碳平衡等缺少可靠输入或项目参数的复杂公式，显示“计算待配置”，不得沿用演示结果。

数据状态：有效、缺失、异常、不适用、计算无效、计算待配置。业务状态：正常、预警、告警、未判定、参考。缺失或异常的依赖不能生成正常业务结论。未覆盖项不计为正常项。

## 4. 来源与刷新

原始值以人工日填报为主，也支持受控表格导入。水量、电量、商品药剂量等填日累计；浓度等填人工整理的日均值；台数、名称等填当日记录。累计量不是累计表底读数；单次观测或特殊范围需在说明中注明，不假装已自动汇总。具体提示集中在 `daily-input.ts`，不改变旧数据数值或单位。

示范场景须明确确认，仅补未保存草稿中的空白项；已维护数值（包括0）、目标控制方式/容差、异常、不适用及填写过说明的日数据不被样例覆盖。设计文件来源不被示范操作替换。全部含示范来源的记录保留待校核标识。控制方式/容差编辑不自动注入示范目标。缺失值永不回退到样例。

刷新诊断：读取当前已保存运行数据、按业务日期匹配有效设计版本与工况、执行公式、生成逐项结果和数据覆盖说明。保存的历史结果不随新标准/新工况变化。来源变化后提示重新生成。

## 5. 保存、锁定与追溯

每次保存保留序号、时间、操作者和原因。诊断版本冻结指标定义、单位、设计值、目标值、实际值、偏差、状态、解释、公式/规则版本、设计版本、工况版本、运行数据版本。列表显示最新版本，历史版本可打开。

锁定后不得直接更新。更正必须填写原因并重新生成/保存。已使用的工况采用停用，不硬删除。删除仅适用于未锁定、未被诊断引用的日记录，并明确提示将连同其本地修订一起删除；已引用版本不可删除。当前不是正式审计存储，生产后端应增加恢复与权限控制。

旧浏览器数据保持原样。缺少项目/工艺线身份或缺少完整快照的旧数据不能静默归属当前项目或补造成正式历史结果；提供明确的旧记录查看/导出或显式导入，不自动改变旧键。

## 6. 页面设计

沿用主产品导航、蓝/浅灰/白共享组件。设计为单页维护；工况为列表与矩阵；运行和诊断为日期列表与详情；日报只读。指标分类页签、搜索和表内状态筛选减少长表负担。顶部显示日期、工艺线、有效工况和保存状态。

## 7. 验收场景

完整样例、缺失数据、无工况、零值/零目标、区间/上下限、公式依赖缺失与除零、同日再次保存、锁定后更正、工况区间重叠、不同项目隔离、旧记录不被覆盖、设计/工况修改后历史快照不变、日报与诊断一致、导出和打印。

## 8. 参考依据

生态环境部 [HJ 2038—2014 官方发布文本](https://www.mee.gov.cn/ywgz/fgbz/bz/bzwb/other/hjbhgc/201406/W020140619563569370189.pdf)，参考第4、5、11章的运行管理、按设计与实际工况管理、记录与档案思想。本标准为指导性标准；本软件的日记录唯一性、快照和版本规则是产品设计决定，并非标准规定的软件实现要求。具体参数以项目设计资料、适用规范和现场确认结果为准。

## 9. 本批实际实现与后续校核

- 规则版本 PM-0.1.1，集中维护 36 个受控计算映射：进水浓度比、浓度法去除率、MLVSS/MLSS、SVI、浓度/污泥浓度比、水量负荷、分段及总 HRT、日气水比、内外回流比、商品吨水药耗、填料体积比。
- HRT 使用有效池容与日进水量并乘 24，不计回流；总 HRT 不把二沉池加入生化池。当前气水比使用同日日累计标准气量，不能从瞬时风量假定 24 小时运行。药耗以商品质量计，不冒充有效成分消耗。
- 浓度比不是 F/M 负荷或硝化反硝化速率；浓度法去除率不是质量负荷去除率。上述解释随诊断快照保存。
- 流化气水比、污泥龄、理论碳源/碱度、膜片堵塞及尚未明确依赖的能耗/沿程模型不拼凑计算。当前默认 138 项诊断中，完整示范仍有 28 项未判定，需逐项校准后再扩展。
- 工况暂定容差默认预警 10%、告警 50%，都是沿用原型的待校核项目参数，不是正式行业标准；部分样例目标可能与新明确的统计口径不一致，不能直接用于现场调控。
- 本期工艺线选项暂沿用一期/二期；设计和工况详情均可点击修订版本只读查看，编辑基于最新版本。诊断可下钻历史来源。工况停用后不再参与重新匹配，已保存诊断不变；历史日期重算的工况选择策略仍需细化。
- 本地写入有版本冲突检测、失败保护、窗口级草稿暂存，不能替代后端事务与审计。项目数据切换隔离；旧档案保留，不自动归属缺失身份的数据。
- 2026-09-06 已验证真实浏览器导出68项日数据模板和138项日报文件，并回读检查内容；真实工作簿导出→解析往返及错误拦截由自动测试覆盖。浏览器文件选择被环境权限拒绝，未宣称页面导入链已验收。
- 新增页面内完整日报预览（无论当前筛选如何均展示全部快照行）。已打开 Chrome 系统 A4 横版打印预览，表头重复、黑白内容及末项可见；当前样例打印9页内容另有1张空白尾页，仍待修正，不宣称归档打印完全验收。见 `verification-20260906.md`。
