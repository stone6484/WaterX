# WaterX UI 规范 · Components 1.0 第一批

状态：已确认，纳入 Components 1.0 正式基线\
依赖：WaterX Foundations 1.0\
覆盖组件：Global Navigation、Filter Toolbar、Status & Progress；同步固化 Data Table 与 Table-attached Tabs 基线\
验证案例：首页工作台、工艺诊断分析、管理质量·经济高效

## 1. 组件化原则

- 组件只使用 Foundations 1.0 中已经确认的颜色、字号、间距、圆角、边框、阴影和密度变量。
- 页面不得复制组件样式后各自修改近似值；差异必须通过组件属性、状态或明确的业务变体表达。
- 新组件进入开发前必须覆盖 Default、Hover、Focus、Disabled，以及适用的 Selected、Expanded、Loading、Error 状态。
- 任一共享组件发生调整，都必须在三个基准案例中回归检查。
- 本批组件实现参考资产为 `waterx-components-core.css`，类名统一使用 `wx-` 前缀，避免与现有业务样式冲突。

## 2. Global Navigation

### 2.1 组成

Global Navigation 由以下部分组成：

1. 顶部栏：品牌区、当前项目、用户信息、退出操作。
2. 左侧导航：折叠按钮、一级目录、展开箭头、二级目录、滚动区。
3. 固定图标资产：`assets/waterx-nav-icons.svg`。

### 2.2 尺寸

| 项目 | 规格 |
|---|---:|
| 顶部栏高度 | 56px |
| 桌面左侧导航宽度 | 192px |
| 1280px 及以下导航宽度 | 180px |
| 折叠导航宽度 | 56px |
| 一级目录最小高度 | 40px |
| 二级目录最小高度 | 34px |
| 导航图标 | 18 × 18px |
| 展开箭头 | 16 × 16px |
| 导航滚动条 | 1px |

### 2.3 状态

- Default：透明背景、普通文字、浅水青图标。
- Hover：使用低透明度水青背景，文字变白。
- Expanded：一级目录文字使用 500 字重，箭头向下，显示二级目录。
- Selected：使用 `#0D6387` 背景和左侧 3px 高亮线，文字与图标为白色。
- Collapsed：仅保留一级图标，隐藏文字、箭头与二级目录。
- Focus Visible：使用 Water Blue 600 的 2px 外轮廓。

### 2.4 行为规则

- 用户主动折叠后，页面切换期间应保持折叠状态。
- 一级目录有子项时才显示箭头；无子项时不保留空箭头位置。
- 展开箭头必须是几何对称折线，收起向右、展开向下。
- 图标和目录的业务映射固定，不得因刷新、页面或操作系统而改变。
- SVG Sprite 的 `<use>` 必须保留稳定的外部资源路径和片段 ID，不得被构建工具内联为 `data:` URL；生产构建后必须刷新验证图标完整显示。
- 导航内容溢出时只允许纵向滚动；滚动条默认弱化，悬停时稍增强。

## 3. Filter Toolbar

### 3.1 结构顺序

标准顺序为：

> 筛选字段 → 更新 → 保存 → 弹性留白 → 页面状态汇总

更新与保存按钮必须紧跟最后一个筛选字段，不得漂移到工具栏最右侧。页面级“正常 / 预警 / 告警”汇总只出现一次。

### 3.2 尺寸与布局

| 项目 | 规格 |
|---|---:|
| Select / Date / Button 高度 | 36px |
| 同一工具栏字段内容框 | 等宽 |
| 字段标签与控件间距 | 7px |
| 字段之间间距 | 8–10px |
| 按钮之间间距 | 8px |
| 工具栏至首个业务表面 | 8px |
| 紧凑操作按钮 | 72 × 36px |

- 工具栏通过留白建立层级，不使用外围卡片、瓷片式容器或底部分隔线。
- 筛选框内容居中；更新、保存使用 72 × 36px，并紧跟最后一个筛选字段。
- 字段宽度以完整显示常用内容为目标；空间不足时按断点统一收缩，不单独压缩某一字段。
- 常用桌面宽度仍不足时，优先压缩非业务留白；不得删除字段标签、状态文字或关键操作。
- 不允许筛选字段自动变成高低不齐的多行布局；确有需要时应定义独立的窄屏变体。

### 3.3 控件状态

- Default：Neutral 200 边框，白色背景。
- Hover：Neutral 300 边框。
- Focus：Water Blue 600 边框和低透明度 2px Focus Ring。
- Disabled：Neutral 25 背景、Neutral 100 边框、Neutral 400 文字。
- Primary Button：Water Blue 700 背景和白色文字。
- Secondary Button：白色背景、Neutral 300 边框、Water Blue 700 文字。

## 4. Status & Progress

### 4.1 语义映射

| 语义 | 主色 | 适用情况 |
|---|---:|---|
| 正常 | `#2F9E6F` | 达标、范围内、正向结果 |
| 预警 | `#F28C28` | 轻度偏差、需要关注 |
| 告警 | `#D94A4A` | 严重偏差、异常、超限 |
| 信息 | `#0877A7` | 当前选择、普通信息、非风险进度 |

### 4.2 状态汇总

- 状态点直径为 7px，必须同时显示数字和状态文字。
- 页面状态汇总只出现一次，默认放在筛选工具栏右侧。
- 不得在页面多个看板重复显示“正常 / 预警 / 告警”图例。

### 4.3 异常计数

- 分类页签只显示预警和告警数量，正常数量不显示。
- 数量为 0 时不渲染计数标识，不保留空白占位。
- 计数使用 14px 橙色或红色实心圆，数字使用白色 8px / 700，与 12px 页签标题行高协调。

### 4.4 状态标签

- 定性、区间型状态使用圆角标签，例如“范围内”“需要关注”“重点关注”。
- 区间状态不使用数值进度条。
- 标签必须包含文字，不得只通过颜色传达状态。

### 4.5 定量偏差

- 定量偏差使用“数值文字 + 3px 进度条”。
- 数值文字、状态判断和进度条必须共用同一语义色。
- 蓝色进度不得用于业务偏差、风险或评分预警。
- 进度条长度表达偏差程度，但不能替代精确数值。

## 6. Data Table 已确认基线

以下规则立即应用于工艺诊断、经济高效及其他常规业务表格：

- 统一使用 `Table Surface`：Neutral 0 背景、1px Neutral 200 外边框、8px 圆角。
- Surface 内部四周留白 20px；表格横线在左右两侧各留 20px，并与 Surface 底边保留 20px。
- 表格本体与单元格不设置左右竖线；外层 Surface 提供区域边界，内部只使用横向分隔线。
- 表头使用 Neutral 25、12px / 400、高度 44px，避免深色重表头。
- 表头上边线与下边线均为 1px Neutral 100，颜色和粗细完全一致，并在 Surface 左右各保留 20px。
- 表头上下线、常规行分隔线和最后一行底线均为 1px Neutral 100，不通过加粗末行表达结束。
- 简单数据行 44px；带实际值备注、状态说明等双层内容的复杂数据行 60px。
- 列内容不得遮挡或重叠；内容能够完整展示时按业务比例均衡铺满，不得保留无业务意义的大面积列间空白。
- 表头和表体共用同一套列宽定义；可按页签或内容复杂度提供列宽变体，不使用一套过宽最小宽度强制所有页签滚动。
- 内容确实放不下时才设置内容安全的最小宽度并启用局部横向滚动；横向滚动条使用 4–6px。
- 纵向滚动条为 1px 低对比度，透明轨道，Hover 时轻微增强。
- 纵向溢出时拆分为固定 Header 与可滚动 Body；Header 及其上下横线保持固定。纵向滚动条只属于 Body，从 Header 下方开始，右边缘与 Header 右边缘对齐。
- 并列看板等宽；左侧外间距、中间距、右侧外间距必须相等，桌面 16px、紧凑断点 8px。
- 必要业务备注可放在表格外下方；自证性、无业务价值的解释不进入业务页面。
- 表头配置入口应并入最后一个业务表头并靠右，不得创建只有表头存在、数据行缺失的空列。
- 相同原则适用于简单指标表、复杂双层信息表和其他常规业务表格；特殊矩阵、冻结列或编辑表格另定义例外。

## 7. Table-attached Tabs 已确认基线

- 适用范围：仅用于与下方表格直接关联的数据分类选择，例如“进水水质”“进水特征”。
- 高度 44px；标题默认 12px / 400；默认状态不逐项套框。
- Hover：Neutral 25 底色、1px 浅边框、14px 顶部圆角，不出现 Water Blue 强调线。
- Selected：Neutral 25 底色、1px 浅水蓝边框、3px Water Blue 500 顶部强调线、14px 顶部圆角，标题 12px / 600；取消下边框，与表格连续。
- 页签组与 Table Surface 上、左、右边框均保留 20px，选中底色不得贴住外框。
- 异常计数使用 14px 橙/红实心圆；0 不显示，正常数量不显示。
- 首页时间切换、抽屉 Tabs 等普通页签不得直接套用此变体。
