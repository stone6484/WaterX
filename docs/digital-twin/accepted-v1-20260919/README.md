# WaterX 澄川数字孪生示例 V0.1

完全假想的 10 万 m³/d 地上式经典 A²/O 水厂，独立于主产品。

- 打开 `index.html` 进入三维示例。所有依赖本地提供，无需联网。
- `scenario.html`：可读、可打印的案例设计与完整台账。
- `case-data.json`：25 个设施、96 个设备、547 个信号、45 条流路。
- `data.js` 与 JSON 内容一致，供直接打开页面使用。
- `vendor/THREE-LICENSE.txt`：Three.js MIT 许可。

交互：拖动旋转、右键平移、滚轮缩放；平面视图；地面漫游时拖动转向、WASD/方向键移动、Esc 返回总览；剖切隐藏水面、前侧池壁和建筑屋顶以查看内部；巡检路线切换七个观察站点。移动端保留触摸旋转、对象点击及巡检路线。

巡检记录仅保存当前浏览器 localStorage（键 `waterx-twin-demo-v1-inspections`），可导出 JSON；保存失败会提示。不存在正式工单写入或设备控制。

所有参数与业务记录为示例，真实项目接口、完整室内/碰撞系统、地下完整管网、精确水力高程、动态生化模型均未实现。

## 主视图风险示例增补

默认显示综合风险示例：2 号风机故障（告警）、进水泵房硫化氢报警（告警）、1 号风机轴承温度偏高（预警）、1 组 DO 测点离线（预警）。中间视图同时提供数字汇总、可点击风险列表、对应位置的红/橙色灯与标记；同一鼓风机房的两条事件集中显示，统计仍按事件计数。

点击列表或空间标记定位对象，右侧展示当前模拟值、触发依据、影响和核验方向。普通名称关闭不影响风险标记；对象不在视野内时，顶部风险列表仍可访问。正常情景清除风险标记，离线值保持缺失，绝不显示为零。

温度 75 °C 和硫化氢 10 ppm 仅为这次交互演示自设触发线，未经工程确认，不是通用设备限值或职业接触限值。示例值与风险由 app.js 的示例情景叠加在基础数据之上，case-data.json 保留原始正常示例快照。未增加报警确认、真实通知或自动控制。


## 场景细节与读数增强（2026-09-19）

- 风机：分片机柜、进气格栅、控制面板、铭牌、状态灯、消声器、排气管、法兰螺栓和压力表；水泵：电机壳、散热筋、蜗壳、吊耳、导轨、线缆和出水立管，内回流泵另用轴流外形。四台进水潜污泵位置下移至示意湿井内，数据文件中的空间位置同步修改。
- 生化池：棕褐色混合液、分区水面微动、好氧区细泡、供气总管与下垂支管、池顶走道和护栏；池壁使用程序生成的混凝土纹理。管道增加圆滑接头、法兰和部分支座。
- 主视图取消独立读数卡，改为设施与设备旁的紧凑读数标注，通过引线对应实体、随视角定位，并避让风险面板及其他标注。生化池展示 DO、MLSS、厌氧/缺氧 ORP、流量与氨氮；进出水展示流量、pH、COD、氨氮、TN、TP 等；剖切近景显示风机、水泵及 DO 仪表读数。与模拟信号页共享计算，回放同步，离线仍为缺失。拥挤时优先保留选中对象与主要工艺读数。
- 左右资料与风险面板默认展开并固定，均悬浮在工具栏下方，距场景顶边和侧边 16px，不挤压三维场景宽度。点击“收起”后保留右缘“资料”入口；靠近入口临时展开，点击入口展开，点击“固定”保留。取消固定后支持移出自动收起；键盘可聚焦入口、使用收起按钮或 Esc。
- 一键回正仍恢复顶视、关闭剖切并恢复资料默认展开，不改动当前情景、回放时刻及已保存巡检记录。

## 顶部工艺导航（2026-09-19）

移除左侧对象栏，工艺导航位于顶部操作按钮组右侧，前置“选择”：预处理 → 生化处理 → 二沉及回流 → 深度处理与消毒 → 污泥处理 → 辅助设施。悬停或点击展开设施与所属设备，只显示名称，不显示内部编码。全部 25 个设施、96 个设备均可从下拉列表直接定位。支持下方向键进入、Tab 切换、Esc 关闭和点击空白关闭。

本轮在现有浏览器验证：主视图与页面同宽（884 px）；设施和设备定位、选择后关闭下拉、回正正常；菜单无内部编码，控制台无新增错误。

## 悬浮面板与工具栏（2026-09-19）

- 风险提示可收起为左上侧报警灯悬浮球，点击展开，支持固定/取消固定；未固定时移出面板自动收起，键盘焦点在面板内时保留。
- 悬浮球按当前模拟事件判色：无事件为绿色，仅预警为黄色，含任意告警为红色。提示文字同步说明状态与数量，收起不关闭场景风险标记。
- 对象资料移到三维视图区内，与风险面板采用相同顶边距、圆角、边框和阴影。流路图层已移至顶部“辅助设施”后的下拉菜单，可同时勾选水、回流、空气、污泥/回水和加药；勾选时保持菜单展开。
- 操作顺序为三维总览、平面视图、地面漫游、巡检路线、一键回正、剖切/去顶、名称。工艺导航靠右，前置“选择”；窄窗口自动换行。
