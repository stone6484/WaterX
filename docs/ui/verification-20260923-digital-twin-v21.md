## 真实边界

这是主产品内的高保真示例模块。人员、考勤、位置、信号、风险和任务为预设或浏览器示例，不查询线上真实生产数据。人员位置固定在示例日08:00，不随回放伪装成实时定位。示例工单/指令仅保存在当前浏览器，不发送实际消息，不改变设备参数或替代审批。

管线路径和尺寸用于场景可读性，不是施工/碰撞校核成果；水面动画不是水力仿真。后端工程化、跨设备同步、正式任务权限、真实定位/取数/设备控制均未纳入本次。

没有新数据库迁移、账户重置、CDS配置变更。现有构建大包提醒保留。隔离预览工作台显示业务职责来源不完整，不作为孪生错误修复或生产全流程验证。
