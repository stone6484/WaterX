# Sprint 0–1 验收清单

- [ ] 能通过环境变量创建首个平台管理员，仓库中没有默认密码。
- [ ] 用户可登录、刷新令牌、退出和修改首次密码。
- [ ] 平台管理员能看到两个示例污水厂。
- [ ] 切换厂区后，只返回该厂组织和员工。
- [ ] 无厂区授权时，服务端返回 403，不能通过修改请求头越权。
- [ ] 两厂均包含厂级组织、部门和班组示例。
- [ ] 管理端能展示组织、人员和当前厂区。
- [ ] 手机 H5 可在常见手机宽度正常显示。
- [ ] Flyway 可在空 PostgreSQL 上完成全部迁移。
- [ ] 后端测试、前端类型检查和生产构建通过。
- [ ] 页面、数据和资源中不含特定水务集团 Logo 或品牌视觉。
