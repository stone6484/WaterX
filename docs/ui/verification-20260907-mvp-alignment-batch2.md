## 范围和修改

1. 管理质量共用页面（经济高效、合法合规、稳定达标、安全运行）：表头上下均为 1px 浅线，含边线高度 44px；按真实表体滚动条宽度同步表头右侧留位，避免列错位。纵向滚动条仅在表体内，Chromium 使用 1px 低对比样式，Firefox 回退原生 thin。保留局部横向滚动、备注、实际值加粗及原操作入口。
2. 偏差文字和风险得分条使用现有红橙绿语义令牌，不重新定义风险。评分导航的普通得分占比不是风险结论，统一品牌蓝，不再随选中态变成预警色；符合冻结规范中普通完成度的非风险例外。修正窄桌面旧样式导致总分跨列、末项换行和周期文字溢出的问题。
3. 工艺维护共用 `MetricEditor.vue`（工艺设计标准 / 工况目标 / 人工日数据）：单位独立成列，固定表头与可滚动表体分离；短内容按剩余空间均分列宽，长内容在本组件横向滚动，长名称和单位可换行。表头 44px、复杂数据行最小 60px，内部横线统一 1px，无内部竖框。保留所有原输入、状态、来源说明和更新事件；项目容差说明置于表格下方。
4. 新增无需登录的工艺维护预览 `ProcessEditorLab.vue`，直接引用产品组件，不复制一个静态视觉样稿。支持三种模式、三种宽度、长字段 / 短字段 / 空数据、只读 / 编辑；演示数值和容差不构成业务标准，不调用 API 或保存档案。

主要文件：`apps/admin-web/src/modules/management-quality/ManagementQualityPage.vue`、`apps/admin-web/src/modules/process-management/MetricEditor.vue`、`apps/admin-web/src/ui-lab/ProcessEditorLab.vue`、`apps/admin-web/src/ui-lab/UiLab.vue`。
