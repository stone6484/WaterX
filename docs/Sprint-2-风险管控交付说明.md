# Sprint 2 风险分级管控交付说明

## 当前可用能力

- 多厂风险数据按 `tenant_id + site_id` 强制隔离。
- 支持区域、风险对象和危险源台账。
- 支持设备设施、区域场所和作业活动三类风险对象。
- 支持 LS 与 LEC 两种评估方法，计算结果保存参数、分值、规则版本和快照。
- 默认 LS 分级：1–7 蓝、8–12 黄、13–16 橙、17–25 红。
- 默认 LEC 分级：不高于 69 蓝、70–159 黄、160–319 橙、320 及以上红。
- 自动生成班组/岗位、部门/车间、厂级、厂级主要负责人四档管控层级。
- 支持工程技术、管理、培训教育、个体防护、应急处置五类措施。
- 支持草稿、待审核、生效、退回和停用状态。
- 提交前强制校验已完成评估且至少存在一项管控措施。
- 审核退回必须填写原因，审核操作进入审计日志。
- 管理端提供四色统计和风险清单，切换污水厂后自动刷新。
- 管理端提供风险辨识向导，可一次完成基本信息、LS/LEC 评估、五类措施并提交审核。
- 待审核记录可在清单中直接通过或填写原因退回。
- 手机 H5 支持独立登录、多厂切换和已生效岗位风险告知。
- H5 风险卡展示危险因素、事故类型、管控层级及具体现场管控要求。
- 支持厂区区域树查询、新建、编辑和安全停用约束。
- 支持危险源关联组织、岗位或人员责任，并记录管控职责与频次。
- H5 员工可对当前评估版本执行“已阅读并确认”，系统记录人员、时间和客户端来源；风险复评后需要重新确认。
- 已生效风险可发起 LS/LEC 复评，复评结果在审核通过前不替换当前生效版本。
- 复评审核通过后旧评估保留为历史，新评估成为当前版本，并自动触发重新告知确认。
- 管理端风险详情展示历次评估、当前版本、复评原因、审核状态和当前确认人数。

## API

- `GET /api/v1/risk/summary`：四色及待审核统计。
- `GET /api/v1/risk/objects`：风险对象列表。
- `GET /api/v1/risk/hazards`：危险源与当前评估列表。
- `GET /api/v1/risk/hazards/{id}/measures`：读取风险的现场管控措施。
- `POST /api/v1/risk/hazards`：新建危险源草稿。
- `POST /api/v1/risk/hazards/{id}/assessments`：执行 LS/LEC 评估。
- `PUT /api/v1/risk/hazards/{id}/measures`：维护五类管控措施。
- `POST /api/v1/risk/hazards/{id}/submit`：提交审核。
- `POST /api/v1/risk/hazards/{id}/review`：审核通过或退回。
- `POST /api/v1/risk/hazards/{id}/reassess`：发起风险复评。
- `GET /api/v1/risk/hazards/{id}/assessments`：查询评估版本历史。
- `POST /api/v1/risk/assessments/{id}/review`：审核复评结果。
- `GET /api/v1/risk/hazards/{id}/acknowledgement-summary`：查询当前版本告知确认统计。
