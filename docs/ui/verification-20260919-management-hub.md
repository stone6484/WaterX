## 范围与最新决定

以设计工作区 `outputs/waterx_management_cockpit_20260919/handoff/accepted-light-v1/` 的十一专题浅色快照及 `个人工作台开发补充.md` 为依据。用户本轮追加决定：**个人工作台并入管理驾驶舱，作为生产运行前的首个默认页签；左侧仅保留管理驾驶舱入口**。这覆盖初始设计中两个独立入口的安排。

## 保留的边界

1. 个人页读取服务端业务记录；本轮服务是隔离验收库。十一管理看板均为固定示例，不等于当前项目实绩，不混入真实合计。
2. 未生成的周期检查计划缺稳定责任ID，暂不按姓名归属；保养、培训、工艺/设备个人风险来源未接。
3. 已完成/确认按当前责任关联记录展示，不是完整操作审计。日数据无截止时间，不推断逾期；风险优先目前基于本人事项期限，尚非全厂风险引擎。
4. 工作台日数据跳转后端协作记录；原工艺导航仍保持浏览器本地档案默认配置，两者不自动互相同步。
5. 示例阈值/管理质量分值非正式标准，示例优化变化非已实现收益。未验证实厂人员全部业务闭环、极端长文本和所有浏览器。
6. 5173/8080仅本地服务生命周期内有效；凭据不进入Git、文档或截图。旧8085服务未中断。发布须另行授权。
