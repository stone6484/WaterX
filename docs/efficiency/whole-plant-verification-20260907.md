## 2. 实际实现

| 专题 | 本轮核算能力 | 必须保留的边界 |
| --- | --- | --- |
| 水量平衡 | 外部进出水、库存变化、未解释差额/比例、内部回水单列；直接量/表底读数换算；计量包含与重复路径拦截 | 未解释差额不等于漏损；零流入比例无效但差额仍可有效；库存缺失不默认为0 |
| 污泥平衡 | 液态浓度及湿泥含水率换算干固体、外加固体/返流/库存/转化、加权含水率、处理能力、库存情景、返流氨氮及所列资源成本 | 不预测生化产泥；SS/TS可比性、独立去向证据未确认不宣布闭合；商品药量不等于外加干固体 |
| 能效系统 | 独立消耗总表、互斥实测分项、估算、未分配差额、吨水电耗、价格/用量费用因素 | 购电不未经确认冒充消耗；负差额保留；费用变化不等于节约收益 |
| 药剂与成本 | 实际投加与采购领用分开、液体密度换算、分药种有效量/单耗、碳源有效当量、所列成本 | 不加总不同药种有效量；碳源纯度不代替有效当量；不是全口径经营成本 |
| 能力与瓶颈 | 同流路串联阶段最小值、阶段内并联和共享限制、当前负荷裕量 | 量纲相同仍需同物质/同干固体口径；缺整个阶段不能出完整能力；复杂交叉网络需分边界 |
| 水力高程 | 同基准同期自由水面差、设计对照、已配置水位约束；显式确认可减扬程后的能量试算 | 压力段/跨泵段不给自由水面替代结论；试算是估算，不等于实测节电 |
