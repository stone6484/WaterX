# 市政污水处理厂安全生产管理平台一期功能验收清单

## 交付范围

- 多厂组织、人员与厂区数据隔离
- 安全培训课程编制、任务指派、学习考核、区间统计、人员资质录入和到期提醒
- 培训 PPT、视频、PDF、Word 材料上传与课程关联
- 岗位安全承诺书编制、推送、阅读、电子签订和个人档案归档
- 访客安全告知内容维护、风险分布图、疏散路线图、二维码、免登录阅读确认和入厂登记
- 风险辨识、LS/LEC 评估、四色分级、管控措施、审核、复评和岗位确认
- 综合、重点部位、班组、季节及节假日检查计划与任务
- 隐患上报、整改、附件、验收、催办和逾期升级
- 十类危险作业申请、两级审批、安全措施、气体检测、交底、开工和完工验收
- 特种设备、安全附件、消防器材、应急物资建档、检验有效期和维保记录
- 职业病危害因素录入、接触岗位、检测周期、检测登记和员工职业健康体检档案
- 年度安全预算编制、费用登记、分类使用、余额和执行率

## 一期边界与后续建议

一期已形成核心业务闭环和可预览产品。正式生产部署前仍需结合实际组织完成真实人员导入、角色授权、短信或企业消息通知渠道、生产级文件存储、数据备份、等保与安全测试；这些属于实施上线工作，不影响一期产品功能验收。
