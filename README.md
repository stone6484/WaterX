# 市政污水处理厂安全生产管理平台

一期可运行工程，支持多租户、多厂组织权限、登录会话、厂区切换、组织人员、风险分级管控、安全检查与隐患整改、危险作业、安全培训与资质、设备与应急物资、职业健康及安全投入。产品使用中性视觉，不包含任何特定水务集团 Logo 或品牌资产。

## 当前交付

- `apps/admin-web`：Vue 3 + TypeScript 管理端。
- `apps/mobile-h5`：Vue 3 手机现场端。
- `packages/api-client`：共享 API 客户端与类型。
- `backend`：Java 21 + Spring Boot API。
- `deploy/docker-compose`：PostgreSQL、Redis、MinIO 本地环境。
- `docs/adr`：关键架构决策记录。

当前已实现：

- 环境变量初始化首个管理员，源码不保存默认密码；
- 访问令牌、刷新令牌、刷新轮换、退出和首次改密；
- 租户、集团/区域、污水厂、组织、岗位、员工、角色和权限表；
- 服务端厂区数据范围校验；
- 两个示例污水厂、部门、班组、岗位和人员档案；
- 管理端登录、厂区切换、组织架构和人员列表；
- H5 现场工作台，支持风险确认、检查执行、隐患上报与整改、危险作业现场控制、培训考核和承诺书签订；
- Flyway 数据库迁移、OpenAPI 和健康检查。
- 区域、风险对象、危险源、评估规则版本和五类管控措施数据模型；
- LS、LEC 自动计算，生成四级四色风险和默认管控层级；
- 风险草稿、提交审核、通过生效、退回修改闭环及审核日志；
- 管理端按厂展示风险四色统计、待审核数量和风险管控清单。
- 风险复评保留历史版本，审核生效后自动触发员工重新阅读确认。
- 检查模板、检查任务、任务统计与行业检查项示例。
- 隐患上报、整改反馈、验收通过或退回的闭环状态流转。
- 管理端检查任务与隐患台账，手机 H5 隐患上报与整改反馈。
- 周期检查计划按每日、每周、每月或一次性规则自动生成任务，并防止重复派发。
- 手机端支持隐患发现照片/文件和整改凭证上传，管理端按隐患汇总展示材料；单文件限制 10MB，并校验图片、PDF、Word、Excel 类型。
- 周期检查计划支持暂停和恢复，操作原因自动留痕；检查任务与隐患超过期限后自动标记逾期，隐患支持催办并累计催办记录。
- 隐患逾期按 1–3 天一般提醒、4–7 天部门督办、8 天以上厂级升级分级；管理端汇总闭环率、隐患级别、发现来源和升级数量。
- 危险作业统一作业票底座覆盖有限空间、动火、临时用电、高处、吊装、动土、盲板抽堵、断路、涉水和设备检维修 10 类，已跑通申请、安全审核、负责人批准和完工关闭流程。
- 培训课程创建、PPT/视频/文件上传、员工指派、考核、指定时间范围统计及个人档案归档。
- 主要负责人、安全员、特种作业和特种设备人员证书录入与到期提醒。
- 岗位安全承诺书编制、员工推送、移动端签订与个人档案归档。
- 访客安全告知内容编辑、风险分布图、疏散路线图、二维码和免登录登记。
- 特种设备、安全附件、消防器材和应急物资建档、检验/有效期提醒及维保记录。
- 职业病危害因素录入、检测登记、到期提醒和员工职业健康体检档案。
- 年度安全预算编制、费用使用登记、余额与执行率统计。

## 环境要求

- JDK 21
- Maven 3.9+
- Node.js 20+
- pnpm 11+
- Docker 与 Docker Compose（常规本地运行推荐；仅执行后端测试时不强制）

当前工作区已在 `.tools/runtime` 隔离安装 JDK 21 和 Maven，不会修改系统 Java 环境。可直接使用：

```bash
./scripts/backend-test.sh
```

该命令会临时启动真实 PostgreSQL、执行 Flyway 和接口集成测试，结束后自动关闭数据库；无需 Docker。

## 首次启动

1. 复制根目录 `.env.example` 为 `.env`，修改全部密码。
2. 在项目根目录加载 `.env` 中的变量。
3. 启动 PostgreSQL、Redis 和 MinIO：

   ```bash
   docker compose --env-file .env -f deploy/docker-compose/docker-compose.yml up -d
   ```

4. 启动后端：

   ```bash
   cd backend
   DATABASE_PASSWORD="$POSTGRES_PASSWORD" mvn spring-boot:run
   ```

5. 安装前端依赖并启动管理端：

   ```bash
   pnpm install
   pnpm dev:admin
   ```

6. 手机 H5：

   ```bash
   pnpm dev:h5
   ```

管理端默认地址为 `http://localhost:5173`，H5 为 `http://localhost:5174`，API 文档为 `http://localhost:8080/swagger-ui/index.html`。

## 管理员初始化

首次运行时设置：

- `BOOTSTRAP_ADMIN_USERNAME`
- `BOOTSTRAP_ADMIN_PASSWORD`，至少 12 位

系统仅在管理员账号不存在时创建账号，并使用 BCrypt 保存密码哈希；首次登录必须修改密码。创建成功后应从部署环境移除明文初始化密码。

## 数据安全约束

- 所有业务查询必须包含 `tenant_id`。
- 厂级接口必须验证当前用户是否有权访问请求的 `site_id`。
- 组织、人员、风险、检查、隐患等历史对象只停用，不级联物理删除。
- 不在代码、数据库迁移或文档中提供弱口令。
- 示例人员仅为档案，不自动创建可登录账号。

### 磁盘空间

2026-07-22 检查结果：本机数据卷剩余约 56 GB，当前项目约 608 MB，其中约 546 MB 是项目内隔离的 JDK/Maven 工具。源码、前端依赖和构建产物占用较小。

建议开发期间至少保留 10 GB 可用空间；安装 Docker Desktop、PostgreSQL、Redis、MinIO 及镜像缓存后，常见总增量约 5–10 GB。`node_modules`、`backend/target`、前端 `dist`、Maven 缓存和容器镜像均可重新生成，空间不足时可优先清理，不能删除数据库卷、上传附件和源资料。
