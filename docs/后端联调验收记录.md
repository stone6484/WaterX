# 后端联调验收记录

验收日期：2026-07-21

## 环境

- Apple Silicon macOS
- Eclipse Temurin JDK 21.0.11+10
- Apache Maven 3.9.16
- 临时真实 PostgreSQL 14.22
- Spring Boot 3.4.7

## 已验证

- 项目编译成功，单元测试通过。
- Flyway V1、V2 在空 PostgreSQL 数据库顺序执行成功。
- 环境变量可安全初始化首个平台管理员。
- 管理员登录成功，访问令牌可鉴权 `/api/v1/auth/me`。
- 管理员保持首次登录必须改密状态。
- 平台管理员可查询两个示例污水处理厂。
- 指定第一厂区可查询 7 个组织单元。
- 指定第二厂区可查询 2 名示例员工。
- 集成测试完成后 PostgreSQL 自动停止，不保留测试密码和业务数据。

## 联调中发现并修复

- PostgreSQL JDBC 无法推断 `Instant` SQL 参数类型。令牌过期时间已改为明确的 SQL `Timestamp`，避免登录签发会话时报错。

后端测试共 2 项，失败 0、错误 0，构建成功。
