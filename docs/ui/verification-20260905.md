| 键盘 Tab | 跳过禁用按钮，下一可操作按钮呈现焦点环 |
| 缺失 / 零值 / 检出限 / 历史值 | 分别保留 `—`、`0`、`<0.02`、原数值及说明；不显示正常标签 |
| 空数据 / 加载 / 读取失败 / 无权限 | 不保留其他场景的记录；各有对应提示；加载含忙碌语义、失败为 alert |
| 验收台控制台 | 实测会话无警告或错误记录 |

## 重复执行方法

启动开发服务后打开 `ui-lab.html`，按上表切换数据场景与容器宽度；通过表单输入空值、负数、0，并使用 Tab 检查键盘状态。修改样例数据时，应保留上述边界场景，不只检查“所有值正常”的截图。
