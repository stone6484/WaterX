## 本批修正

1. 删除新模块的棕色预警硬编码，使用统一的预警文字色 `#C45F05`、图形色 `#F28C28`；绿色 `#2F9E6F` / `#1E704D`、红色 `#D94A4A` / `#B83232` 同理区分图形和文字。
2. 页签分别显示非零橙色预警、红色告警计数，不再合并成一个棕色数字。14px 实心圆、白字，选中态圆角和水蓝顶部强调，悬停不加蓝色强调。
3. 定量偏差恢复彩色百分比和 3px 细条，条长沿用冻结样例的 8% 最小可见长度及 100% 上限。条长只编码偏差幅度，颜色仍完全取自原有业务状态，不能由条长重判严重性。
4. 范围内、文本或无法形成数值偏差的状态使用文字标签；缺失、未配置、参考状态不会画成正常进度条。实际值加粗，编码和来源备注保留。
5. 恢复指标意义列，说明来自现有指标目录，仅用于当前展示，不改历史快照。两侧齿轮调用既有配置入口；名称按钮仍打开原有规则、来源与版本详情。
6. 双看板等宽；两侧与中间间隔采用同一令牌。外框内留白 20px；表头上下与内部横线统一 1px，无内部竖线。页签及表头 44px；带编码、来源的复杂数据行最小 60px。
7. 固定表头和数据滚动区分离，滚动条从表头下方开始。Chrome 数据区纵向滚动条实际占用 1px；Firefox 使用原生细滚动条回退，不保证精确 1px。
8. 当前分类的内容决定列宽，剩余空间平均分给七列。短内容铺满，长内容局部横向滚动。浏览器对固定表格的混合百分比列宽处理不符合预期，最终使用容器实测宽度分配像素列宽，并扣除实际纵向滚动条宽度；避免首列空白、列错位与取整造成的伪横向滚动。
9. 诊断页的历史/原因区及汇总区去掉额外卡片外框；保留业务说明、版本、状态、现有操作，不删业务信息来模仿静态样例。
