# 市政污水处理厂安全生产管理平台现场试运行验收方案

## 一、试运行目标

验证系统在真实厂区、真实岗位和手机网络条件下能够支持安全管理闭环，确认数据准确、权限合理、操作可执行、记录可追溯。

建议选择一个污水处理厂先试点，周期为 2 周；试点稳定后再推广至其他厂区。

## 二、参与人员

- 厂长或主要负责人：确认审批流程和管理责任。
- 安全经理、安全员：维护基础数据并组织业务验收。
- 运行、运维、质控班组长：执行检查、隐患和危险作业场景。
- 一线员工：使用手机端完成风险确认、培训和现场反馈。
- 设备、职业健康及财务相关人员：核对专项台账。
- 系统管理员：记录问题、修正数据并保障试运行环境。

## 三、准备工作

1. 使用《真实数据导入模板》准备一个厂区的组织、人员、证书、设备、职业危害和风险基础数据。
2. 按《角色权限矩阵》配置试点账号，每类角色至少准备 1 个账号。
3. 准备可在厂内手机网络访问的测试地址和二维码。
4. 准备 1 门培训课程、1 份承诺书、1 份检查计划和 1 张危险作业测试票。
5. 试运行数据使用明确的“测试”标识，严禁与正在生效的纸质作业许可混淆。

## 五、验收标准

- 必测场景通过率 100%，不得遗留阻断业务或造成数据错误的问题。
- 高风险权限问题、跨厂数据问题、审批绕过问题必须全部关闭。
- 表单关键字段、日期、金额和人员关联准确，附件能够打开。
- 手机端在厂区常用网络和主流手机浏览器中操作顺畅。
- 关键业务记录可查询到操作者、时间、厂区和状态变化。

## 六、问题分级

- P0：数据泄露、跨厂访问、审批绕过、数据丢失；立即停止试运行。
- P1：核心流程无法继续或结果错误；上线前必须修复。
- P2：局部功能不便但有替代方式；形成修复计划。
- P3：文字、布局和体验优化；纳入后续迭代。

## 七、试运行结论

试运行结束后，由厂长、安全经理、试点班组负责人和系统管理员共同确认：通过、限期整改后通过或不通过。所有 P0/P1 问题关闭并完成回归测试后，方可扩大到其他厂区。
