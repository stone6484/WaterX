## 数据与状态口径

- `waterx-demo-data.js` 是本地工艺管理 / 工艺总览共享的示例来源：MLSS 3400、MLVSS 2380、SVI 112、SRT 14.2、内回流 195%，以及原有进水、生化、沉淀、最终出水水质。B 池 DO 2.8 与本页好氧末端 DO 0.48 是不同测点。
- SV₃₀ = SVI × MLSS / 10000 = 38.08%；VSS/SS = MLVSS / MLSS = 0.70。卡片 SV₃₀ 保留一位小数，计算使用未舍入值。
- 09-18 09:30 为参数示例快照，化验按同日 08:00，SRT 为最近完整日结果。中间取样点、配水、曝气、泥位等为设计补充，不是同一水团的追踪或完整物料平衡。
- 药剂 75 / 125 kg/h 为商品液量，对应原有每日 1800 / 3000 kg 示例，不表示有效成分或 COD 当量。
- 最终出水目标复用原驾驶舱示例，不宣称排放合规。厌氧 TP 上升不自动按最终出水限值判警。
- 沉降图按格子中心值计算：SVI 50–150 绿，<40 或 >200 红，其余黄；当前蓝点为真实示例坐标。F/M–SRT 图：F/M 0.05–0.15 且 SRT 10–20 为绿，SRT <5 或 >30 为红，其余黄。以上为概念分区，不能作为普适诊断规则。
- 污泥卡片超参考区间为黄色关注；异常情景 SOUR <8 为红色演示分级。流程参数红 / 绿 / 蓝表示偏高 / 范围内 / 偏低。空值不判健康。
- “双向关联”表示需联合观察，不表示确定的即时因果或调节建议。页面没有生产控制操作。
