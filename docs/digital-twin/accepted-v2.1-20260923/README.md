## 这次视觉细化

- 12 类设备全部换用可辨认的实体结构；泵类区分潜污泵、轴流回流泵、干式离心泵及计量泵。补充机壳、散热筋、吊环、导轨、电缆、底座、法兰、仪表面板和局部旋转部件。
- 鼓风机增加隔音罩、百叶、控制屏、消声器、排气管和压力表；仪表有遮阳罩、支架、探杆和线缆。DO 仪表位置微调到池边，曝气系统位置对应好氧段中部，data.js 与 case-data.json 同步。
- 生化池区分平缓的棕褐色混合液与好氧区局部细泡、浮沫。曝气盘与池底管网连通，避免原粗模和新阵列重复叠加。清水/二沉池使用较平缓的灰绿色水面、细微波纹及环境反射。均为视觉动画，不是水力/生化仿真。
- 圆池增加中心进水筒、检修桥、环形出水槽、堰及栏杆；建筑增加窗框、百叶、门缝、压型屋面、天沟和落水管；矩形池增加压顶、施工缝、梯子及检修步道。
- 道路、混凝土和草地使用 ambientCG CC0 材质的颜色、法线和粗糙度贴图；补充路缘、排水篦子、井盖、灯杆、围栏和轻量植被。
- 管道增加弯头、法兰螺栓、焊缝和支撑。进水泵支管与总管、风机排气口与空气总管已补齐连接。
- 重复构件采用实例化；静态构件按对象/材质合并，保留独立的点击身份、风险着色、剖切、水面及旋转部件。

既有工艺导航、点击台账、直接读数、风险提示、图层多选、剖切和漫游/巡检入口保留。
